# Hibi 日々

Tu día a día, en papel y tinta. App personal que funciona en el iPhone desde la pantalla de inicio.

Ábrela en Safari: https://joanpintto.github.io/hibi/ y elige Compartir → Añadir a pantalla de inicio.

Tus datos se guardan solo en tu móvil; este repositorio contiene únicamente el código.
